# Admin panel

Built on [minimal-ui-kit/material-kit-react](https://github.com/minimal-ui-kit/material-kit-react) (MIT, see `LICENSE.md`).
The kit's theme, layouts and components are kept; its demo pages and mock data are removed.

```bash
npm run dev        # http://localhost:3039 — proxies /api to API_PROXY_TARGET (default http://localhost:4000)
npm test           # vitest + Testing Library
npm run lint:fix   # ESLint (import order follows the kit's perfectionist rules)
npm run build
```

See the root README for the architecture and the full workflow.
